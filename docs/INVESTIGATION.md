# Lauer–Vigneau Family Investigation

## Purpose

This project is an interactive, evidence-backed family tree supporting an adoption / biological-family investigation for a woman born in 1979.

The site must keep **pedigree facts** separate from **research hypotheses**.

## Evidence rules

Include information in the base family tree when it is supported by one or more of the following:

- Official/public records.
- Birth years supplied by the user from court records.
- Marriage dates supplied by the user from Emmet County records.
- Explicit relationships shown in Facebook family sections.
- Relevant information found in public Facebook posts.
- Facts independently verified by more than one source.
- DNA-supported family structure.

Do **not** convert an inference into a pedigree fact.
